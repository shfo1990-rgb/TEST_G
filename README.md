# NEON STACK: CYBER TOWER

HTML5 기반으로 제작하여 Android 및 iOS 앱으로 패키징하는 수익형(광고 기반) 모바일 하이퍼캐주얼 게임 프로젝트입니다.

---

## 🚀 완료된 주요 기능
- [x] **게임 엔진 코어**: 3D 등각투영(Isometric) 캔버스 렌더러
- [x] **AABB 슬라이스 알고리즘**: 완벽한 절단 판정 및 중력 낙하 파편 물리
- [x] **손맛(Juiciness) 연출**: 네온 스파크 파티클(40개), 화면 쉐이크(Camera Shake), 모바일 햅틱 진동
- [x] **콤보 회복 기믹**: 퍼펙트 4회 연속 성공 시 블록 크기 회복 (+25px)
- [x] **피버(FEVER) 모드**: 점수 2배 폭발 및 화려한 황금 네온 점등
- [x] **다이나믹 속도 가속 곡선**: 스코어 증가에 따른 1.0x ~ 2.8x 점진적 가속
- [x] **글로벌 리더보드**: 로컬 저장 + 글로벌 가상 라이벌 랭킹 집계
- [x] **신디사이저 사운드**: Web Audio API 무손실 실시간 주파수 합성 (저작권 0%)
- [x] **모바일 네이티브 앱 구조화**: Capacitor 7 + Android 네이티브 프로젝트 완비

---

## 🛠️ 개발 및 빌드 명령어

### 1. 웹 브라우저 즉시 실행
- `index.html` 파일을 더블클릭하여 바로 플레이 및 테스트

### 2. 안드로이드 프로젝트 동기화
웹 게임 소스(`index.html`) 수정 후 안드로이드 앱으로 반영할 때:
```bash
npm run sync
```

### 3. Android Studio로 열기
```bash
npm run open:android
```
