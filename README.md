# NEON STACK: CYBER TOWER

HTML5 기반으로 제작하여 Android 및 iOS 앱으로 패키징하는 수익형(광고 기반) 모바일 하이퍼캐주얼 게임 프로젝트입니다.

- [x] 3D 등각투영(Isometric) 캔버스 렌더러
- [x] AABB 슬라이스 알고리즘 및 추락 물리 파편
